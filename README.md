# GlobeTrek Adventures

GlobeTrek Adventures is a travel booking web application developed for the Web Application Development module at ICBT Campus.

## Features

- User registration and login
- Travel package browsing
- Package details
- Hotel and accommodation listings
- Transport services
- Tour guide information
- Online booking management
- Customer booking history
- Admin dashboard
- Staff dashboard
- Package and booking management

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Bootstrap
- WAMP/XAMPP
- phpMyAdmin

## Installation

1. Clone the repository.
2. Copy the project folder into the WAMP `www` folder or XAMPP `htdocs` folder.
3. Start Apache and MySQL.
4. Create a database named `globetrek_db`.
5. Import `database/globetrek_db.sql`.
6. Configure the database connection.
7. Open the project in a browser.

Example:

```text
http://localhost/globetrek/
